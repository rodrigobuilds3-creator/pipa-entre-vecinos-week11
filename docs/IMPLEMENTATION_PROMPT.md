# Build contract / Pipa entre vecinos

Implement docs/PACKET.md as a buildless, accessible Spanish web app. Keep code in dist/, pure domain logic in dist/core.mjs, controller in dist/app.mjs. Use integer cents and strict bounds. Demo units A-D and provider labels are fixed fictional identifiers. Persist validated state locally, handle denied storage and corrupted state, and serve with offline caching. Implement quote choice, editable allocation before confirmation, payment event log, calibrated delivery estimate, explicit discrepancy review, closure, aggregate export and reset confirmation. Prevent duplicate handlers on rerender, XSS and silent destructive resets. Train deterministic regression on synthetic daily use with holdout metrics; distinguish training data from sensor simulation. Do not make remote data calls. Run node --test tests/*.test.mjs and browser QA before packaging. Record actual bugs, resolutions and deploy identifiers. Refer to the packet for state invariants, privacy and human approval constraints.
